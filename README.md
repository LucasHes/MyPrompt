# My Prompt

A clean and practical prompt editing and management tool that helps you efficiently manage and use your frequently used prompt templates.

![My Prompt Application Screenshot](https://github.com/LucasHes/MyPrompt/raw/main/page.png)

## Features

- **Template Management**: Create, edit, delete, and organize various prompt templates
- **One-Click Copy**: Quickly copy prompt content to clipboard
- **Formatting Tools**: Built-in tools for code blocks, lists, quotes, and more
- **Import/Export**: Support for importing and exporting template configurations for backup and sharing
- **Clean Interface**: Intuitive and user-friendly interface design for a smooth experience

## Installation

1. Download the latest installation package from the [Releases](https://github.com/LucasHes/MyPrompt/releases/tag/AI%2CPrompt%2CEditor%2CTemplate) page
2. Double-click to run the installer and follow the prompts to complete installation
3. After launching the application, you can immediately use the default templates provided or create your own

## User Guide

### Basic Usage

1. Click on a template button on the left to load a preset prompt into the editing area
2. Modify the prompt content as needed
3. Click "Copy" to copy the prompt to your clipboard
4. Paste into any chat interface or editor where you need to use the prompt

### Creating Custom Templates

1. In the "Custom Templates" area on the right, enter a template name (up to 20 characters)
2. Enter the template content in the text box (up to 2000 characters)
3. Click the "Save as Template" button
4. The new template will appear in the template list on the left

### Template Management

- **Edit Template**: Right-click on a template button and select "Edit Template"
- **Delete Template**: Right-click on a template button and select "Delete Template"
- **Import Templates**: Click on "Import Templates" in the top navigation bar
- **Export Templates**: Click on "Export Templates" in the top navigation bar

## Development Information

### Technology Stack

- **Electron**: Cross-platform desktop application framework
- **HTML/CSS/JavaScript**: Front-end interface development
- **Node.js**: Back-end functionality implementation

### Local Development

```bash
# Clone the repository
git clone https://github.com/yourusername/my-prompt.git

# Enter the project directory
cd my-prompt

# Install dependencies
npm install

# Start the development environment
npm start

# Build the application
npm run build
```
